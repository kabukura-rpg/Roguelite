## 実装内容

- 新規プレイのコアはオルカン・S&P500・NASDAQ100の3つ。開始後は変更不可。
- 高配当株・ゴールド・債券をサテライト化。最大2枠、同一資産は重複不可。
- 投資資産の内訳は100%、80/20、60/20/20。現金を含めず、各年とも固定比率を使用。
- 相場の資産別リターンを加重平均してから、既存のカード効果を適用。市場ショックも既存の資産別感応度を加重平均し、選択肢や売買順・抽選回数は維持。
- 高配当株の配当は割当部分だけに発生。通常は全額現金へ。「配当再投資」取得時のみ配当の50%を投資へ戻す。戦略カードの配当金には適用しない。
- 4・8・12・16年目の通常結果と突発イベントの終了後、専用乱数で未取得3候補を提示。12年目は成長→カード報酬の順。
- 生活防衛資金、積立投資、配当再投資、現金管理の4方針を実装。金額・比率・発生年は `PORTFOLIO_CONFIG` に集約。
- 生活防衛資金は生活支出10%軽減。元の強制売却に追加ペナルティがないため、新しいペナルティは設けない。
- 積立は取得翌年から年初に投資10,000円・現金10,000円。現金管理は年末の出来事の後、現金比率10%未満なら翌年の年初に現金10,000円。ショップ退出や再開で二重加算しない。
- HUDに現在の比率、詳細に長期方針、成長画面に3候補、成績にFINAL PORTFOLIOとLONG TERM STRATEGYを追加。スマホの成長候補は横スワイプ。
- セーブのキー・バージョン・読み書き関数は変更せず、新しい状態を既存の保存方式に含める。旧セーブの追加フィールドは初期値で補い、旧仕様の守備資産コアもそのプレイでは維持する。成長候補を保存し、再開で再抽選しない。

資産リターン表・予報の内部分類と精度・既存の乱数列・相場確定の順番・カード定数・突発イベント定義・ランク境界・称号条件・目標額・Pages設定は変更していません。サテライトの保有年数を既存の資産保有集計に含めるため、金ピカ投資家などの既存称号は保有資産に応じて判定されます。

## シミュレーション結果

**600シード（0〜599）×3コア×7成長選択方針×カードあり／なし＝25,200プレイ**。実際の3候補から選ぶ進行を使用しています。サテライトを強制付与した比較ではなく、希望候補がなければ長期方針を取得します。希望構成との一致率も集計しました。

カード選択はプレイヤーに公開される景気の観測材料だけを参照します。相場の内部分類・未来の結果は参照しません。ショップは双方利用せず、市場ショックはホールド、生活支出は支払い、日常は最初の無料選択肢に統一しています。

|コア|カードなし：目標到達率の範囲|カードあり：目標到達率の範囲|カードあり：最終資産中央値の範囲|
|---|---:|---:|---:|
|オルカン|2.0〜6.3%|33.0〜48.0%|248.3〜282.8万円|
|S&P500|11.2〜19.5%|53.5〜62.3%|319.5〜379.8万円|
|NASDAQ100|19.0〜24.0%|55.5〜61.0%|346.9〜408.5万円|

今回確認できた傾向は次のとおりです。**数値は調整していません。**

1. この操作方針では、すべてのコアで「長期方針優先」が目標到達率の最大値でした。積立などの外部資金を早期に獲得しやすく、サテライトを増やす選択との機会費用があります。ただし希望構成は固定できず、長期方針優先でも38.5%のプレイがサテライト1つを保有します。
2. 守備サテライトには下振れ抑制の効果があります。たとえばNASDAQ100・カードありでは、長期方針優先の最大DD中央値−46.4%に対し、ゴールド＋債券優先は−36.2%。一方、最終資産中央値は408.5万円から347.6万円へ下がりました。安全性と成長性の両方で一律に優れる構成は、この比較では確認できません。
3. オルカン＋ゴールド・債券優先でカードなしは**12/600プレイ＝2.0%**しか目標に届かず、かなり厳しい条件でした。同じ選択方針でカードありは33.0%です。オルカン全般でカードなしの目標到達が難しい点は、次回のバランス判断材料です。
4. カードありの到達率は最大62.3%で、全条件が簡単に300万円へ達する状態ではありません。特定サテライトを取得しないとクリアできない傾向も見られません。ただし高難度・最適プレイを含む全戦略の証明ではありません。
5. 今回の全25,200プレイで総資産0円の破産は0件でした。これは既存の「破産より最終ランクで緊張感を出す」傾向と整合します。極端なレバレッジ連打など別の操作方針はこの集計に含みません。

成績には相場利益だけでなく年間積立・現金補充も含まれます。その額は別列に記録しています。サテライトごとの厳密な優劣を判断するには、成長取得年と方針の組み合わせを揃えた追加比較が必要です。

全42条件と再現方法は [シミュレーション結果](portfolio-simulation.md)、個別データは [CSV](portfolio-simulation.csv) と [JSON](portfolio-simulation.json) に保存しています。
